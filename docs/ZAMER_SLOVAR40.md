# Замер этапа 40 — коды саморезов: ШУЖ для пола + без выдуманных характеристик

**Проблема (UAT заказчика 2026-08-05).** На «саморезы для крепления полов» бот предлагал **ШСГД**
(шуруп гипсокартон-дерево) и вдобавок фантазировал, что он «с пресс-шайбой» (у ШСГД потайная головка,
острый наконечник — пресс-шайбы нет). Заказчик подсказал, что для пола лучше **ШУЖ** (универсальный
жёлтый), но через два дня бот снова выдал ШСГД. Второй вопрос заказчика: «обучается ли бот на подсказках».

**Диагноз.** (1) Бот сам НЕ обучается: история в Redis 30 мин и только внутри диалога; правки
закрепляются только словарём/данными. (2) «для пола / крепление пола» никуда в подтип не разведено →
падало на «Шуруп сантехнический» (лаг-винт, вообще мимо). (3) Бот приписывал головку/наконечник,
которых нет в наименовании прайса (в имени только код+размер, признаков нет — модель домысливала).

**Решение (только словарь/данные + промт, тракт поиска/вектор не тронуты).**
- **Маршрут пол→ШУЖ** (`materialy.json → слово_в_имени`, механизм этапа 37): формы «пол/пола/полов/
  половой/напольный/настил…» бустят токен «шуж» (+4) в саморез-семействах. Отдельного «для пола»
  самореза в прайсе нет — ШУЖ (универсальный жёлтый, канон «саморез универсальный в дерево») и есть
  правильный ответ.
- **Справочник расшифровок** `data/kody_samorezov.json` (из файла заказчика `Саморезы_ЧАТ-Бот.xlsx`):
  код → расшифровка/головка/наконечник/применение (ШСГД, ШСГМ, ШСММ, ШУЖ, ШУЦ, ШС КРОВ, ШС ГВЛ, ШС ПШ,
  ШС ОК). `Poisk.harakteristiki_koda(имя)` матчит код по префиксу имени (длинные раньше: «ШС КРОВ» до
  «ШСГД»). Расшифровка уходит в tool-payload агента полем «характеристики».
- **Правило SYSTEM** (`agent.py`): головку/наконечник/назначение называть ТОЛЬКО из наименования или
  поля «характеристики»; не выдумывать (у ШСГД пресс-шайбы НЕТ, она у ШСММ/ШС КРОВ).

## Проверка

**Поиск (лексический Poisk):**
- `саморез для пола` / `для крепления полов` / `крепить пол` / `для настила` → **ШУЖ** (было: Шуруп
  сантехнический).
- Дефолт сохранён (этап 37): `саморез для гипсокартона` → ШСГД; `гипсокартон по металлу` → ШСГМ.
- Расшифровка по имени верна для всех кодов; у некодовых (Гвоздь) → None.

**Агент (`run_agent`, живой вызов OpenRouter):**
- «саморезы для крепления полов» → «подойдут универсальные жёлтые ШУЖ…» (не ШСГД).
- «что такое ШСГД? он с пресс-шайбой?» → «Потайная головка, острый наконечник. **Без пресс-шайбы**.
  Если нужна пресс-шайба, это уже ШСММ.» (расшифровка из справочника, фантазия убрана).
- «чем прикрутить половую доску к лагам» → ШУЖ 3,5×40/50 с ценой и остатками.

**Регресс (`baseline_v2`).** Правка `слово_в_имени` бустит токен «шуж» только в саморез-семействах;
floor-слова в наборах отсутствуют (0 в слепом/размерном/абстейн; 1 в золоте — `кран шаровый пол дюйма`,
где «пол дюйма»=полдюйма, ШУЖ не кандидат → top-1 `Кран шар. 1/2` не изменился). Справочник расшифровок —
agent-only, на ранжирование `baseline_v2` не влияет.

**Гибрид-`baseline_v2` 2026-08-06:** абстейн 91% / разговорный 78% / родовой 89% / размер 85% /
размерный точный 94% / золото 35/40 — **до последней цифры идентичен прогону этапа 41** (правка пол→ШУЖ и
справочник ранжирование не затронули). Разговорный/золото — тот же вектор-RRF-шум, что и на этапе 41.
